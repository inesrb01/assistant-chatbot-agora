# Cahier des charges - Agora Chatbot Stage

## Besoin

Les étudiants, enseignants et membres de l'administration perdent du temps à chercher des informations dans l'intranet. Le projet propose un assistant chatbot capable de répondre aux questions fréquentes et de montrer les sources internes utilisées.

## Utilisateurs

- Étudiant : consulter horaire, documents, reprise d'examen, support.
- Enseignant : procédures pédagogiques, notes, documents.
- Administration : gestion des demandes et suivi.

## Fonctionnalités obligatoires

- Authentification avec comptes démo
- Tableau intranet
- Chatbot en français
- Recherche dans une base de connaissances
- Sources internes affichées
- Documents filtrés par rôle
- Demande de rendez-vous
- Historique des conversations

## Technologies

- Frontend : React, Vite, CSS
- Backend : Node.js, Express, JWT, Zod
- Données : JSON
- Tests : node:test
